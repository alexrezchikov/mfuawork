## Bash как язык программирования

`BashScript.md`

### Что такое скрипт и чем он отличается от программы

* **Скрипт** — это файл с инструкциями для операционной системы на каком-либо языке программирования, который можно выполнять сразу после создания, без компиляции. Интерпретатор (в нашем случае — Bash) читает файл построчно и сразу выполняет команды.
* **Программа** — это скомпилированный файл, содержащий двоичный (машинный) код. Перед запуском её нужно собрать компилятором, зато работает она обычно быстрее и не требует установленного интерпретатора.

### Первые команды

```shell
echo "Привет, Мир!"
```
```shell
echo "Сегодня: $(date)"
```
```shell
echo "Текущий пользователь: $USER"
```

Здесь:
- `echo` — выводит текст в терминал;
- `$(date)` — подставляет результат выполнения команды `date` (текущую дату и время);
- `$USER` — переменная окружения, хранящая имя текущего пользователя.

### Первый скрипт

Файл скрипта на Bash: `script.sh`

```bash
#!/bin/bash
echo "Привет, Мир!"
echo "Сегодня: $(date)"
echo "Текущий пользователь: $USER"
echo "Как вас зовут?"
read name
echo "Привет, $name! Добро пожаловать в bash-скриптинг"
```

**`#!/bin/bash`** — это **shebang** (шибэнг). Первая строка скрипта, которая говорит операционной системе, каким интерпретатором выполнять этот файл. Без неё ОС не будет знать, что это bash-скрипт, и попытается выполнить его как обычную программу.

`read name` — читает строку, введённую пользователем с клавиатуры, и сохраняет её в переменную `name`.

> **Важно:** чтобы запустить скрипт, его нужно сделать исполняемым:
> ```shell
> chmod +x script.sh
> ./script.sh
> ```

### Проверка существования файла

```bash
#!/bin/bash

read -p "Введите имя файла: " filename

if [ -f "$filename" ]; then
    echo "Файл '$filename' существует."
else
    echo "Файл '$filename' не найден (или это не обычный файл)."
fi
```

Разбор:
- `read -p "..." filename` — выводит приглашение и сразу читает ввод в переменную `filename`;
- `[ -f "$filename" ]` — проверка: существует ли файл и является ли он обычным файлом (не каталогом);
- `if ... then ... else ... fi` — условная конструкция. Если условие истинно, выполняется блок после `then`, иначе — после `else`;
- `fi` — закрывает конструкцию `if` (слово `if` наоборот).

> Кавычки вокруг `"$filename"` обязательны: они защищают от ошибок, если в имени файла есть пробелы.
