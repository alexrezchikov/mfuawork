Запуск **Redis**
```shell
docker run -d --name my-redis -p 6379:6379 redis:alpine
```

![1](/mfuawork/2_DB&OS/Docker/Redis/1.png)

Подключиться к **Redis CLI**
```shell
docker exec -it my-redis redis-cli
```

Внутри Redis: ping → PONG, SET key value, GET key - ?
